# little-lemon-food-ordering-app
Little Lemon Mobile Food Ordering App
Little Lemon Food Ordering App Project Overview 

Little Lemon is a SwiftUI-based iOS food ordering application designed to provide users with a simple and convenient restaurant browsing experience.

Main Features User onboarding and registration. Home screen with restaurant information. Food categories and menu items. Search functionality. User profile management. Persistent user information. Logout functionality. Technologies Swift SwiftUI Xcode Project Status 

Academic iOS Capstone Project.
